Privacy Policy

Last updated: 2026-10-14

What this app is

Claude rclone is a personal OAuth client for rclone, operated by and for a single individual. It is not offered to other users.

Data accessed

The app requests only the Google Drive drive.file scope. It can access only files that it created or that were explicitly opened with it. It cannot see other files in Google Drive.

How data is used

Files are uploaded to and downloaded from the owner's own Google Drive for personal backup and sync. Data is not sold, shared with, or transferred to any third party, and is not used for advertising.

Storage

OAuth tokens are stored only in the rclone configuration on the owner's own machines. No data is sent to any server operated by this app; there is none.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.

Contact

Questions about this policy can be posted as an issue at github.com/bechica/oauth/issues.
