Claude rclone

Claude rclone is a personal OAuth client for rclone, used by a single individual to back up and sync their own files to their own Google Drive.

It requests only the https://www.googleapis.com/auth/drive.file scope, which allows access only to files created or opened by this app. It does not read any other files in the user's Google Drive.

This app is not offered to the public and has no other users.
